# Communication loss

## Symptoms
The charge point shows Unavailable in the backend, heartbeats stop, and WeakSignal or OtherError notifications arrive in bursts when it reconnects. Both connectors are affected.

## First checks
Check the modem signal history and whether other charge points at the site are offline. A whole site offline is a router or SIM issue; one charge point is usually its modem.

## Remote fixes
Trigger a remote modem reset. If the SIM has been suspended, raise it with the connectivity provider. Most cases resolve without a visit.

## Close the ticket
Set the resolution cause to comms_loss and note whether a visit was needed.
