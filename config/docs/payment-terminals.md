# Payment terminals and RFID readers

## Symptoms
ReaderFailure on both connectors; drivers report that cards are not accepted. Charging by app still works.

## First checks
Check the payment provider's status page and whether the terminal's certificate has expired. A fleet-wide pattern on one terminal model is a provider issue.

## On site
Power-cycle the terminal. Replace it only after the provider confirms it is not a configuration issue.

## Close the ticket
Set the resolution cause to payment_terminal.
